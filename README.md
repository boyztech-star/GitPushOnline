# GitPushOnline
# 🚀 GitPush Mobile

A clean, mobile-friendly web tool that allows users to upload an entire folder directly to a GitHub repository — without using any terminal or Git commands.

---

## ✨ Features

- 📁 Select folder directly from mobile file manager
- 🔗 Paste GitHub repository URL
- 🔑 Secure Personal Access Token (PAT) authentication
- ⚡ Automatic file upload using GitHub API
- 🔄 Smart retry system (handles conflicts, rate limits)
- 📊 Real-time progress bar and logs
- 📱 Fully responsive modern UI
- 🧠 No backend required (runs fully in browser)

---

## 📸 How It Works

1. Select your project folder  
2. Paste your GitHub repository URL  
3. Enter your GitHub Personal Access Token (PAT)  
4. Click **Push to GitHub**  
5. Done 🎉

---

## 🔐 Security

- Token is sent **directly to GitHub API**
- No data is stored or saved
- No third-party servers involved

---

## ⚠️ Requirements

- A GitHub repository (must exist)
- A valid Personal Access Token with `repo` permission

Generate token here:  
👉 https://github.com/settings/tokens

---

## 🚫 Limitations

- Works best on modern browsers (Chrome, Edge)
- Very large folders may take time due to API limits
- GitHub rate limits may apply

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Modern UI)
- Vanilla JavaScript
- GitHub REST API
